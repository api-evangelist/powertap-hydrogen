# PowerTap Hydrogen

> PowerTap Hydrogen Fueling Corp. is an Aliso Viejo, California hydrogen fueling technology company
> founded in 2020, operated as a wholly owned subsidiary of the publicly traded PowerTap Hydrogen
> Capital Corp. (NEO: MOVE, OTC: MOTNF, FWB: 2K6B). It builds distributed on-site "blue hydrogen"
> production and dispensing stations on a patented small-scale steam methane reforming (SMR) platform
> with embedded carbon capture, converting natural gas and municipal water into high-purity hydrogen
> at the point of use.

## API status

PowerTap Hydrogen publishes **no public API**. As of 2026-08-26 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/SOAP contract, no SDK, no MCP server and no A2A agent card
on any host the company controls. Every `/.well-known/*`, `/openapi.json`, `/swagger.json`, `/api-docs`,
`/graphql` and `/llms.txt` probe against `www.powertapfuels.com` and `powertapcapital.com` returned 404.
The only machine-readable endpoint on either host is the default WordPress REST index at
`https://powertapcapital.com/wp-json/` — a CMS-provided surface, not a PowerTap API product.
